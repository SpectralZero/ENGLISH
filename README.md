# خُطوة — English from Zero (Arabic → English)

A mobile-first web app that teaches English to **absolute beginners whose mother tongue is Arabic**.
Everything is explained in Arabic, every English word carries its pronunciation written in **Arabic letters**
(`water → ووتَر`), and every screen is built for someone who has never studied English before.

It is a **static site** — no server, no build step, no npm. Push it to GitHub Pages and it runs.
On iPhone it installs to the home screen and works offline like a native app.

## 1 · النشر على GitHub Pages

```bash
cd path/to/ENG
git init
git add -A
git commit -m "خُطوة — first version"
git branch -M main
git remote add origin https://github.com/SpectralZero/ENGLISH.git
git push -u origin main
```

ثم في GitHub:

**Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save**

بعد دقيقة يصبح الرابط:

```
https://spectralzero.github.io/ENGLISH/
```

### تثبيته على الآيفون
افتح الرابط في **Safari** → زر المشاركة ⬆️ → **إضافة إلى الشاشة الرئيسية**.
سيعمل بعدها بملء الشاشة وبدون إنترنت.

> النطق يحتاج ضغطة واحدة من المستخدم في أول مرة (قيد من Apple على الصوت) — أول ضغطة على أي زر تفعّله.

## 2 · لوحة التحكم (للمشرف فقط)

### كيف تدخل
- الطريقة السرية: **الإعدادات → اضغط على سطر رقم الإصدار في الأسفل ٧ مرات**
- أو مباشرة: `https://.../ENGLISH/#/console`

كلمة المرور الافتراضية: **`khutwa`** — غيّرها فوراً من تبويب **أدوات → كلمة مرور اللوحة**.
لتثبيت كلمة المرور الجديدة على كل الأجهزة، انسخ الـ hash الذي يظهر لك وضعه في
[`app/config.js`](app/config.js) في السطر `passHash`.

> **بصراحة تامة:** هذا موقع ثابت (static) — أي شخص خبير يستطيع فتح ملفات الجافاسكربت ورؤية شاشة اللوحة.
> الحماية الحقيقية ليست كلمة المرور، بل **توكن GitHub**: بدونه لا يستطيع أحد تغيير أي محتوى منشور.
> التوكن يُحفظ في متصفحك أنت فقط ولا يُرفع مع الموقع أبداً.

### التبويبات الستة

| التبويب | ماذا يفعل |
|---|---|
| 📚 **المحتوى** | كل الدروس: تعديل، حذف، ترتيب، إضافة درس جديد. داخل الدرس: كلمات وجمل بالكامل |
| ⚡ **إضافة سريعة** | نموذج واحد سريع: كلمة + معنى + مثال → «حفظ وإضافة أخرى» بدون مغادرة الشاشة |
| 📥 **استيراد** | الصق مئات الكلمات دفعة واحدة (سطر لكل كلمة) مع معاينة قبل الاستيراد |
| ☁️ **النشر** | يعرض الملفات المتغيّرة وينشرها إلى GitHub بضغطة واحدة |
| 🔄 **مزامنة تقدّمي** | ربط مستودع خاص لحفظ تقدّمك ومزامنته بين أجهزتك |
| 🛠️ **أدوات** | فحص المحتوى (نطق ناقص/مكرر/بلا مثال)، توليد النطق تلقائياً، نسخة احتياطية، كلمة المرور |

### صيغة الاستيراد الجماعي

```
english | العربية | example sentence | ترجمة المثال | النطق (اختياري)
```

```
water | ماء | I drink water. | أنا أشرب الماء.
bread | خبز
sun | شمس | The sun is hot. | الشمس حارة.
```

الحقلان الأولان فقط مطلوبان. النطق بالحروف العربية **يُولَّد تلقائياً** إن تركته فارغاً
(مسودة تقريبية — راجعها وعدّلها، فهي تساعدك ولا تغنيك).

## 3 · إعداد توكن GitHub (مرة واحدة لكل جهاز)

1. GitHub → **Settings** → Developer settings → **Personal access tokens** → **Fine-grained tokens**
2. **Generate new token** → Repository access: **Only select repositories** → اختر `ENGLISH`
3. Repository permissions → **Contents: Read and write**
4. انسخ التوكن → الصقه في **لوحة التحكم → النشر → التوكن** → اضغط **اختبار الاتصال**

بعدها: أضف كلمات ← اضغط **نشر** ← تظهر على الموقع خلال دقيقة تقريباً.

> لا تريد استعمال توكن؟ استخدم زر **«تنزيل الملفات بدل النشر»** وارفع ملفات JSON يدوياً إلى GitHub.

## 4 · مزامنة تقدّمك بين أجهزتك (اختياري)

تقدّمك يُحفظ أصلاً على الجهاز فقط. لو أردت أن يتبعك بين الآيفون والحاسوب:

1. أنشئ على GitHub مستودعاً جديداً — **اجعله Private** (مثال: `english-progress`)
2. أنشئ توكناً بصلاحية **Contents: Read and write** على هذا المستودع
   (يمكن أن يكون التوكن نفسه إن أعطيته صلاحية على المستودعين)
3. في التطبيق: **الإعدادات → بياناتي → ☁️ تفعيل المزامنة** → الصق التوكن → **تفعيل** (اسم المستخدم والمستودع مملوءان مسبقاً)
4. كرّر نفس الخطوة على جهازك الثاني بنفس المستودع

بعدها يعمل كل شيء وحده: التطبيق يزامن عند فتحه، وبعد ٢٠ ثانية من آخر إجابة، وعند إغلاقه، ويظهر لك سطر
«مزامنة التقدّم» في **الإعدادات → بياناتي** مع زر يدوي ووقت آخر مزامنة، بالإضافة إلى زر ↻ في الشريط العلوي.

**كيف تُحلّ التعارضات؟** لا يوجد «الأحدث يفوز» أعمى. النسختان تُدمجان حقلاً بحقل:
كل كلمة تأخذ سجل المراجعة الأحدث لمساً، كل يوم يأخذ أعلى نقاط، والسلسلة والنقاط
تأخذ الأكبر — فلا تضيع جلسة ذاكرتَ فيها على جهاز بينما كنت تراجع على الآخر.
(١٦ اختباراً آلياً يغطّون هذا الدمج.)

> **صديقك الذي أعطيته الرابط لن يملك التوكن** — لذلك يبقى تقدّمه على جهازه وحده،
> ولا يستطيع الوصول إلى مستودعك الخاص ولا رؤية تقدّمك. لا تُدخل التوكن على جهازه.

## 5 · العمل محلياً

```bash
node scripts/serve.mjs          # http://localhost:8080
node scripts/check-content.mjs  # فحص كل ملفات المحتوى
node scripts/make-icons.mjs     # إعادة توليد الأيقونات
```

ثم افتح `http://localhost:8080/scripts/test.html` لتشغيل **٦٨ اختباراً تلقائياً**
تغطي: سلامة المحتوى، جدولة المراجعة، كشف الكلمات الصعبة، ترتيب الأولويات،
توليد الاختبارات، مجموعة الجمل اليومية، ودمج المزامنة.
الاختبارات تحفظ تقدّمك وتعيده بعد التشغيل، فلا تفقد شيئاً.

لا يوجد `npm install` — لا توجد اعتماديات إطلاقاً.

## 6 · بنية المشروع

```
index.html              الهيكل + شريط علوي وسفلي
manifest.webmanifest    إعدادات تثبيت التطبيق على الجوال
sw.js                   العمل بدون إنترنت (shell: cache-first, data: network-first)
css/theme.css           الألوان والمسافات والأزرار (design tokens)
css/app.css             تخطيط كل الشاشات
app/
  main.js               الإقلاع + تعريف المسارات
  router.js             تنقّل عبر #hash
  store.js              الإعدادات + التقدّم + خوارزمية المراجعة + السلسلة
  data.js               تحميل المحتوى + طبقة المسوّدة (تعديلات غير منشورة)
  tts.js                النطق عبر أصوات الجهاز
  ui.js                 مكوّنات مشتركة (بطاقة كلمة، حلقة تقدّم، أزرار…)
  sync.js               مزامنة التقدّم عبر مستودع خاص + دمج النسختين
  views/                الشاشات: home, units, learn, quiz, review, alphabet, search, stats, settings
  admin/                لوحة التحكم + النشر إلى GitHub + مولّد النطق العربي
data/
  index.json            قائمة الدروس والمستويات
  alphabet.json         الحروف والأصوات المركّبة
  units/*.json          درس واحد لكل ملف
```

### شكل ملف الدرس

```json
{
  "id": "food",
  "title": { "ar": "الطعام والشراب", "en": "Food & Drink" },
  "icon": "🍞",
  "level": 2,
  "words": [
    {
      "id": "fo_water",
      "en": "water", "ar": "ماء", "tr": "ووتَر",
      "pos": "n", "emoji": "💧",
      "ex": { "en": "I drink water.", "ar": "أنا أشرب الماء.", "tr": "آي درِنك ووتَر" }
    }
  ],
  "sentences": [
    { "id": "fo_s1", "en": "I am hungry.", "ar": "أنا جائع.", "tr": "آي آم هَنغري" }
  ]
}
```

`id` يجب أن يكون **فريداً في كل التطبيق** (اللوحة تولّده تلقائياً).
لإضافة درس جديد يدوياً: أنشئ `data/units/<id>.json` ثم أضف سطره في `data/index.json`.

## 7 · بيانات المتعلّم

كل التقدّم (الكلمات المتعلّمة، النقاط، السلسلة، مواعيد المراجعة) يُحفظ في **متصفح المستخدم فقط**
(`localStorage`). لا يوجد حساب، ولا خادم، ولا تتبّع، ولا شيء يُرسل إلى أي مكان —
إلا إذا فعّلت أنت المزامنة (القسم ٤)، وعندها يذهب ملفك أنت إلى مستودعك الخاص أنت وحدك.
يمكن للمستخدم دائماً تنزيل نسخة احتياطية واستعادتها من **الإعدادات → بياناتي**.

> ⚠️ **مهم على الآيفون:** يحذف iOS بيانات المواقع العادية بعد ٧ أيام من عدم الاستخدام،
> بينما التطبيقات المثبّتة على الشاشة الرئيسية مستثناة. لذلك: **ثبّت التطبيق على الشاشة
> الرئيسية وافتحه من هناك دائماً** — أو فعّل المزامنة فلا تفقد شيئاً مهما حدث.

## 8 · بعد التحديث

عند تعديل ملفات الكود (لا المحتوى)، غيّر رقم النسخة في:
- `sw.js` → `const VERSION = 'khutwa-v1.1.1'` (حتى تصل النسخة الجديدة لمن ثبّت التطبيق)
- `app/config.js` → `APP_VERSION`

المحتوى المنشور من اللوحة لا يحتاج ذلك — يصل فوراً.
